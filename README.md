# 🏛️ Sepahijala District — SWM Grievance Redressal Portal

A modern, serverless Solid Waste Management (SWM) Grievance Redressal Portal built for **Sepahijala District, Tripura** under the Swachh Bharat Mission (SBM) framework.

---

## 🌟 Key Features

- **Civic Blue Design System**: Contemporary, high-contrast civic theme tailored for Sepahijala District, featuring deep navy and vivid orange accents with Poppins & DM Sans typography.
- **Citizen Portal**:
  - Secure, passwordless Email OTP verification.
  - Automatic geolocation capture using HTML5 Geolocation API.
  - In-browser geotagged photo stamping (GPS coords + timestamp watermark) via HTML5 Canvas.
  - Interactive "My Complaints" tracking dashboard with real-time status badges and resolution details.
  - Automated confirmation emails upon complaint submission and status updates.
- **Municipal Admin Dashboard**:
  - Restricted OTP access restricted to authorized emails.
  - Real-time statistics counter (Total, New, In-Progress, Forwarded, Resolved, Rejected).
  - Multi-criteria filtering (by ULB, Status, and search terms).
  - Forwarding grievances across departments or neighboring jurisdictions.
  - Resolution workflow with optional proof-of-work photo upload and citizen notification dispatch.
- **Zero Server Costs**: Powered entirely by GitHub Pages, Google Apps Script, Google Sheets, and Google Drive.
